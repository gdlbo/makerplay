# Shared interpreter corpus for the Kotlin/Rust differential test.
#
# Both implementations read this exact file. One command per line:
#   TYPE|params|strings
# `0x` hex is accepted for packed operator words.
#
# Meta-commands:
#   @choose N   select choice index N
#   @advance    dismiss the current message
#   @vars       dump the numeric bank in key order
#   @strings    dump the string bank in key order
#   @common X       start a common-event body named X
#   @common-id N    start a common-event body registered under numeric id N
#   @end        end the current common-event body
#   @ticks N    run N extra ticks
#
# Waits (180) are covered by unit tests in both implementations rather than
# here: the Kotlin wait uses a wall-clock deadline, so its tick count is not
# deterministic and the comparison would be flaky instead of meaningful.
